# 2026-11-18

## 已掌握页新增「快速复习」

**需求**：已掌握页加快速复习，逐个自评「认识 / 模糊 / 不认识」。

**语义落地（自行确定的口径，用户未进一步指定）**
- 认识：`Storage.skipMasteredReview()` 只把 `nextReview` 按当前 `interval` 顺延（间隔倍数不变），仍留在已掌握。
- 模糊：`Storage.addTodayReviewWord()` 写入当天 daily 记录的 `reviewWords`；`buildQueue()` 把这些词优先排进今天的练习队列，且当天已练过（`learnedWords` 含该词）的不再重复排入。
- 不认识：`Storage.demoteMasteredWord()` 把 stage 打回 1、清 `nextReview`/连续计数，并从当天 `reviewWords` 移除，回到重新学习流程。

**实现**
- `index.html` 已掌握页加「快速复习」按钮 + `.review-session` 卡片会话（计数、发音、三选一、完成小结、退出）。
- `js/app.js` 用模块内 `review` 状态管理会话；结束时重渲染列表；切换词库时关闭会话；会话期间禁用入口按钮。
- `styles.css` 新增 `.review-*` 系列，沿用纸质卡片 token；认识/模糊/不认识分别用 `--positive` / `--accent` / `--negative`，只作语义提示。
- `practice.js` 的 `handleGlobalKeyDown()` 加了「仅练习页生效」守卫：否则在快速复习里按回车/字母会误触发练习判定（顺带修掉旧问题）。

**坑 / 约定**
- 原生 ES 模块改了 `storage.js` / `modules/*.js` 也必须带同一个 `?v=N`，否则浏览器复用旧模块；所有 import 要同步改，否则会出现多份 Storage 实例。
- `hidden` 属性会被 `.review-session { display:flex }` 的作者样式覆盖，已加全局 `[hidden]{display:none!important}`。

**验证**：Chrome headless CDP 跑通 21 项断言（三选一的数据变更、计数、小结、列表刷新、模糊词进入练习队列、零 JS 异常）；1440×900 与 390×844 截图检查无溢出。

## 错题本改动：错误权重只加不减 + 次日连对三次才移出

**需求**：错题的错误权重当日仅加不减、当天不得从错题本删除；错题次日复习，连续三次全对才移除。

**数据模型（storage.js `record()`）**
- 新增 `dailyErrors: {YYYY-MM-DD: n}`：答错就 +1，答对绝不清零（生命周期 `totalErrors` 也只增）。
- 新增 `lastErrorDate`：最近答错日期；`wrongReviewDate`：次日 00:00（`getTomorrowStart()`）。
- 移出条件：`isWrongBook && 今天 > lastErrorDate && consecutiveCorrect >= 3`；当天答错后连对不计数、不移出。旧记录没有 `lastErrorDate` 时视为可移出。
- 移出后 stage=4、interval=3、nextReview=+3 天、`wrongReviewDate=0`；错误权重历史保留。

**队列 / UI**
- `buildQueue()` 把 `isWrongBook` 从「stage2/3 一起进队列」拆出来，只有 `wrongReviewDate` 到期才排入（今天答错的词不回流）。
- 判错提示/跳过提示追加「次日复习」；错题本卡片显示「今日错 N 次 · 次日复习」；列表说明改为新规则。
- ES 模块版本号统一升到 `?v=6`（CSS 未改仍是 v=5）。

**验证**：CDP 16 项断言全过（同日三次答对不移出且权重不变、改日期后三次答对移出并升为 stage4、未到期错题不进队列/到期后进队列）；快速复习 21 项回归测试全过。

### 补充：连对必须落在同一个「无错日」

用户澄清「后续也是同样的打错后当日不再移除，直到首日不出错三次全对」→ 三次连对不能跨日累计，必须在**同一个没有答错的日子**里攒满。
- 新增 `streakDate` 记录连对是哪天攒的；跨日第一次答对先清零再 +1；答错也清零；移出后清空。
- 移出条件收敛为：`今天 > lastErrorDate && streakDate === 今天 && consecutiveCorrect >= 3`。
- 措辞改为「答错当日不移除，首个无错日连对三次才移出」；版本号升到 `?v=7`。
- 验证：新增 3 项断言（跨日两次答对不累计/不移出、同日再两次攒满三次才移出），CDP 19 项全过；快速复习 21 项回归全过。

## 每日复习上限

**需求**：每日复习上限 = 每日计划 × 2，设置里可选 1 / 1.5 / 2 / 3 倍。

**实现**
- `Storage.getSettings()` 合并默认值 `{ dailyGoal: 20, reviewMultiplier: 2 }`（兼容旧存档/同步数据）；`getReviewLimit()` 返回 `floor(dailyGoal * reviewMultiplier)`。
- daily 记录新增 `reviewedWords`（完成复习时由 `nextWord()` 写入，按词去重）；`buildQueue()` 用 `上限 - 今日已复习数` 作为剩余复习额度，队列重建也不会超发。
- 复习词分两级：今日「模糊」标记 + 到期错题为优先；stage 2/3 与到期 stage 4 为普通。超限先砍普通复习。
- 设置弹窗加倍数下拉与实时提示「当前上限 N 词复习 / 天」；CSS 加 `.form-hint` 与 `select.text-input` 箭头。
- 版本号升到 `?v=8`（CSS 同步升，因为设置弹窗样式改了）。

**验证**：CDP 10 项断言全过（1/1.5/2/3 倍上限、向下取整、已完成复习扣减额度、额度归零、设置联动与持久化）；错题本 19 项、快速复习 21 项回归全过；设置弹窗截图检查无裁切/重叠。
